# ReCharge

**Duplicate record — survivor is [`recharge-payments`](https://github.com/api-evangelist/recharge-payments).**

Recharge (formerly ReCharge Payments) is a subscription and recurring-billing platform for
e-commerce, most widely deployed on Shopify. This repo was created from the API Evangelist
secondary-market harvest backlog (a Forge Global private-stock listing) and profiles the same
company already held in the network as `all/recharge-payments`, which carries the deep profile:
10 registered APIs, refined OpenAPI, plans, rate limits, FinOps, authentication, security and
blog artifacts.

No APIs are registered and no artifacts are generated here, deliberately — a second profile would
split one company across two Kin Scores. This record is queued for the duplicate-retirement
procedure.
